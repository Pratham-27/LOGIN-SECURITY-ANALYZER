# Login Security Analyzer

A Python-based security tool that analyzes login logs and detects suspicious authentication activity.

## Features

* Analyzes login attempts
* Detects failed login activity
* Calculates failure rate
* Identifies suspicious IP addresses
* Detects possible brute-force activity
* Provides a simple Tkinter dashboard
* Generates security reports

## Technologies

* Python
* Tkinter
* Log Analysis

## Project Files

* `main.py` – Log analysis
* `gui.py` – GUI dashboard
* `.log` files – Sample login data
* `security_report.txt` – Sample security report

## Purpose

Created to practice Python and understand basic security monitoring and login activity analysis.
